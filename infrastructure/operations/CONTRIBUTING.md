# Изменения и развёртывание

1. Создать отдельную ветку от актуальной main.
2. Внести изменения, проверить diff и создать коммит.
3. Отправить ветку в GitHub и открыть Pull Request в main.
4. Проверить изменения и разрешить обсуждения перед слиянием.
5. После слияния проверить автоматический запуск Jenkins speaker-ci
   и успешное завершение CI/CD.

Прямой push, force push и удаление main запрещены, включая администратора.
Обязательное одобрение другим участником не требуется.
Jenkins запускает проверки после изменения main; обязательных проверок
GitHub перед слиянием сейчас нет.
